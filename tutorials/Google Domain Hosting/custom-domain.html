Set Up a Custom Domain

Go to homepage

01 - Make sure GitHub Pages is working

Publish your site with GitHub Pages first and confirm that its GitHub-provided address loads. If you have not done that yet, start with the website hosting tutorial.

02 - Add your domain in GitHub

Open your repository on GitHub and go to Settings > Pages. Enter your domain in the Custom domain field and save it. Use the domain you plan to serve, such as www.example.com.

03 - Add DNS records with your domain provider

Sign in where you manage your domain's DNS and add the records GitHub Pages requires. For an apex domain such as example.com, add A records pointing to GitHub Pages' current IP addresses. For a www subdomain, add a CNAME record pointing to your GitHub Pages hostname, such as username.github.io.

Use GitHub's official custom domain instructions to confirm the current IP addresses and exact DNS setup for your account.

04 - Wait for DNS to update

DNS changes can take time to spread. Return to Settings > Pages and wait until GitHub confirms the domain is configured. Avoid repeatedly changing records while the update is still in progress.

05 - Check the site and enable HTTPS

Visit your custom domain to confirm it opens the published site. Once GitHub offers the option, enable Enforce HTTPS in the Pages settings so visitors use a secure connection.
