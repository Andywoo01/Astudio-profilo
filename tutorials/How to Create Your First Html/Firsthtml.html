How to Create Your First HTML Page

HTML gives a webpage its content and structure. Follow these steps to make a small page and view it in your browser.

01 - Create a project folder

Choose a code editor, such as Visual Studio Code, and create a folder for your website. In the folder, create a new file named index.html. The .html extension tells your computer that this file contains a webpage.

02 - Add the HTML document structure

Type this starter page into index.html. The doctype identifies modern HTML, the head contains page information, and the body contains the content visitors see.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Webpage</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>This is my first webpage.</p>
</body>
</html>

03 - Add your own content

Replace “Hello, world!” with a heading for your site and change the paragraph to introduce yourself or your project. Use <h1> for the main heading and <p> for a paragraph. HTML tags describe what each piece of content is.

04 - Open the page in a browser

Save the file, then open index.html in your browser. When you make a change, save the file and refresh the browser to see the updated page.

05 - Continue with CSS

Your page now has content. Use the first CSS tutorial to add colors, spacing, and other visual styles. When you are ready to share your site online, follow the GitHub Pages hosting tutorial.
